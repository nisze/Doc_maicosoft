## 🚀 Sobre o Projeto

O **Maiconsoft API** é um sistema completo de gestão empresarial desenvolvido para empresas de construção e materiais. A documentação inclui:

### 🛠️ Tecnologias Utilizadas

**Backend:**
- Java 17 com Spring Boot
- Spring Security (JWT)
- JPA/Hibernate
- SQL Server
- API RESTful

**Frontend:**
- HTML5 semântico
- CSS3 com Flexbox/Grid
- JavaScript ES6+
- Design Responsivo
- Integração com ViaCEP

### 📊 Funcionalidades Principais

- ✅ Gestão completa de clientes
- ✅ Sistema de vendas e cupons
- ✅ Controle de pagamentos
- ✅ Gerenciamento de serviços
- ✅ Dashboard analytics
- ✅ Sistema de usuários e permissões
